# LingoPop! 🇰🇷🇩🇰🇬🇧

日本語の文を見て韓国語・デンマーク語・英語で答える(英語は逆に、英文を読んで和訳する練習も可能)、Duolingo風の語学学習アプリ。
問題は語彙×文型テンプレートから**ボタンを押すたびにその場で生成**されます(各言語 約3,300通り、合計 約9,900通り)。

## 機能

- 4モード: 韓国語 / デンマーク語 / 英語 / 3言語ミックス
- 「問題を生成」で毎回ランダムに**日本語の文**を5問出題 → 選んだ言語で回答
- 回答モードをトグルで切替:
  - 📝 ノート記述: 自分でノートに書いてから「回答を確認」で答え合わせ
  - 🧩 単語タイル: Duolingo風。シャッフルされた単語を正しい順にタップ(ダミー単語入り)
  - 🇯🇵 和訳を入力(英語のみ): 出題の向きが逆になり、**英語の文**を読んで日本語訳をテキスト入力してから答え合わせ。採点は自己申告(書けた/惜しかった/書けなかった)。問題データは既存の英語問題をそのまま反転して使う
- 韓国語はローマ字読み付き(連音化・鼻音化・二重パッチムを反映)
- **🔊 音声読み上げ**: 答え合わせのとき解答文をその言語の音声で自動再生(🇯🇵和訳モードでは出題された英文を出題時に再生)。🔊ボタンで何度でも聞き直せる。ブラウザ内蔵の Web Speech API を使うので追加コスト・サーバー不要(音声はOS依存。対応音声がない言語では🔊ボタンを表示しない)。⚙️オプションのトグルで自動再生のON/OFFを切替
- 全問に文法解説つき(助詞の使い分け、en/et の性、a/an など)
- **🔁 言い換え解説**: 同じ意味を別の動詞・別の言い回しでも表せる問題では、答え合わせのときに「ほかの言い方」を表示(watch a movie → see a movie、좋아해요 → 좋아요(助詞が変わる)、har brug for → behøver など)。模範解答以外にも自然な言い方があることを学べる。採点には影響しません
- GitHubの草風「学習カレンダー」で毎日の学習量を可視化。濃さは**10段階(空+9段階)**で、序盤を細かく・後半をゆるやかに刻んでいます(1問だけの日でも草が生え、最上位は10レッスンぶん)

  | 段階 | XP | 目安 | | 段階 | XP | 目安 |
  |---|---|---|---|---|---|---|
  | 空 | 0 | — | | 5 | 101–150 | 2レッスン |
  | 1 | 1–10 | 1問だけ | | 6 | 151–250 | 3〜4レッスン |
  | 2 | 11–25 | 単語帳の復習1回 | | 7 | 251–400 | 4〜6レッスン |
  | 3 | 26–50 | 1レッスン未満 | | 8 | 401–600 | 7〜9レッスン(金色) |
  | 4 | 51–100 | 1レッスン | | 9 | 601– | 10レッスン以上(濃い金色) |

  しきい値と色を変えたい場合は `index.html` の `GRASS_LEVELS` と `.grass-cell.l1`〜`.l9` を編集してください(セルの色分けと凡例の両方がこのテーブルから作られます)
- ゲーミフィケーション: XP・レベル・連続学習ストリーク🔥・レベルアップ演出・紙吹雪
- **モード別の熟練度**: レベルは「言語 × 出題の向き」の4トラック(🇰🇷韓国語 / 🇩🇰デンマーク語 / 🇬🇧英語(日→英) / 🇯🇵和訳(英→日))で別々にたまる。韓国語をやり込んでも英語や和訳の難易度は上がらない
- **👤 マイページ**: ヘッダーの👤から開く専用画面。トラックごとのレベル・累計XP・出題バランス・出題数と正解率・単語帳の残り数を一覧できる
- **レベル連動の難易度調整**: 全問題に難易度(★〜★★★★★の5段階)が付いており、そのトラックのレベルが上がるほど難しい問題が選ばれやすくなる
- **🎯 難易度を自分で選ぶ**: ホームの「難易度をえらぶ」で「🎚 おまかせ(レベル連動)/ ★ / ★★ / ★★★ / ★★★★ / ★★★★★」を切替。★〜★★★★★を選ぶとレベルを無視して**その難易度だけ**が出るので、「今日はむずかしい文法をやりたい」ときに回り道せず応用問題へ行ける。設定はトラックごとに記憶されるので、🇰🇷韓国語はおまかせ・🇬🇧英語は★★★のような使い分けができる
- **📒 単語帳(間違い復習)**: 間違えた問題(タイル不正解・「書けなかった」)は自動で単語帳にたまり、専用の復習モードで学習。「覚えた!」(+5XP)で単語帳から消え、「まだあやしい」(+0XP)なら残る(覚えていない問題でXPは増えません)。出題の向きも記録されるため、🇯🇵和訳モードで間違えた問題は復習でも英→日で出題される。蓄積数はホーム画面に言語別内訳つきで表示。⚙️オプションのトグルでON/OFF可能(OFF中はカード非表示・自動登録も停止。蓄積データは保持)
- 進捗はブラウザ(localStorage)に自動保存

## 難易度システム

問題は文型ごとに5段階に分類されます。

| 段階 | 名前 | 中身 | 目安 |
|---|---|---|---|
| ★ D1 | 基礎 | be動詞・単文・あいさつ・値段・職業 | 中1前半 |
| ★★ D2 | 標準 | 修飾語・指示詞・所有格・want to・there is疑問文・be動詞の否定 | 中1後半 |
| ★★★ D3 | 応用 | 過去形・経験・because・依頼・頻度・can・will・and/but・疑問詞・様態副詞 | 中2前半 |
| ★★★★ D4 | 発展 | should/have to・比較級・最上級・as…as・現在完了・if/when節・SVOO・SVOC・become・look・There is肯定・過去進行形・that節・不定詞の応用 | 中2後半〜中3 |
| ★★★★★ D5 | 上級 | 後置修飾(分詞)・関係代名詞(主格/目的格)・間接疑問・受身・仮定法過去 | 中3〜高校初級 |

7語以上の長文は1段階引き上げられます(ただし **D1・D2 のみ**。D3以上は文型そのもので難易度が決まるので昇格しません)。

レベルは**学習トラックごとに独立**しています。トラックは「言語 × 出題の向き」で決まり、
`ko`(🇰🇷 日→韓)/ `da`(🇩🇰 日→丁)/ `en`(🇬🇧 日→英)/ `en_ja`(🇯🇵 英→日 和訳)の4つです。
回答モード(📝ノート記述 / 🧩単語タイル)は同じ言語・同じ向きなので同じトラックに合算されます。
🌏ミックスは独立したトラックを持たず、**出題された問題の言語トラックのレベル**で1問ずつ難易度が決まります
(韓国語Lv.2・英語Lv.8なら、同じセッション内でも韓国語は易しく英語は難しく出ます)。

獲得XPはトラック別XPと総合XP(ヘッダーの⚡・🌱草カレンダー)の両方に加算されます。
モード別レベル導入(v1.8.0)より前のデータは、**各トラックの初期XPを当時の総合XPにそろえて**移行するため、
アップデート直後に難易度がいきなり簡単に戻ることはありません。

出題分布は**連続式のなだらかなカーブ**でレベルに応じて変化します。
★〜★★★は従来の式(レベルごとに ★-2.5% / ★★★+2%)のままで、
★★★★は**Lv7から**・★★★★★は**Lv13から**徐々に顔を出し、そのぶん全体を正規化して縮めます。

| レベル | ★ | ★★ | ★★★ | ★★★★ | ★★★★★ |
|---|---|---|---|---|---|
| 1 | 70% | 25% | 5% | — | — |
| 5 | 60% | 27% | 13% | — | — |
| 10 | 43% | 27% | 21% | 9% | — |
| 15 | 27% | 25% | 26% | 18% | 5% |
| 20 | 16% | 27% | 28% | 18% | 11% |
| 25以上(上限) | 14% | 28% | 28% | 17% | 14% |

**Lv1〜6 の分布は5段階化の前とビット単位で同じ**なので、アップデートしても序盤の体験は変わりません。
カーブを調整したい場合は `index.html` の `levelDist()` の係数と上限を変更してください。

獲得XPは難易度と出来によって決まります。**間違えた場合は一律1XP**なので、正解しないとレベルは上がりません。

| | ★ | ★★ | ★★★ | ★★★★ | ★★★★★ |
|---|---|---|---|---|---|
| 書けた / タイル正解 | 10 | 15 | 20 | 25 | 30 |
| 惜しかった(記述のみ) | 5 | 8 | 10 | 13 | 15 |
| 書けなかった / タイル不正解 | 1 | 1 | 1 | 1 | 1 |

高レベルでもD1を14%残し、復習として機能させています。現在の出題バランスはホーム画面のレベルバー下(選択中のトラック)と、👤マイページ(全トラック)に表示されます。

### 難易度を自分で選ぶ

上の表はデフォルトの「🎚 おまかせ」のときの話です。ホームの「🎯 難易度をえらぶ」で ★ / ★★ / ★★★ を選ぶと、
**レベルを無視してその難易度だけが100%出題**されます(`pickQuestions()` が `levelDist()` の代わりに `fixedDist()` を使う)。

- 設定は**トラックごと**(`ko` / `da` / `en` / `en_ja`、加えて🌏ミックス用に `mix` の枠)に `state.diffs` へ保存されます。言語や向きを切り替えると、そのトラックで前に選んだ難易度が復帰します
- 🌏ミックスで固定した場合は3言語すべてが同じ難易度になります
- 📒単語帳の復習は**この設定の影響を受けません**。間違えた問題をそのまま出すのが目的なので、難易度で絞り込みません
- 固定中はホームのレベルバー下と👤マイページの該当トラックが、パーセンテージではなく「難易度: ★★★ むずかしい(固定)」と表示されます
- **XPは難易度に連動します**(★=10 / ★★=15 / ★★★=20 / ★★★★=25 / ★★★★★=30)。高い難易度に固定すればレベルの上がり方は速くなりますが、難しい問題を正解しているぶんなので妥当と判断しました。間違えれば一律1XPという抑制も従来どおり効きます

★★以外は在庫が薄い(各言語で★が約370問、★★★が400〜520問、★★★★が291問、★★★★★が102問。★★が約2,000問)ので、
固定して続けると既出の問題が早めに回ってきます。各難易度の残数は選択したときに説明文へ表示されます。

`diffs` キーを持たない既存の保存データは全トラック「おまかせ」として読まれるため、
アップデートしても出題は従来どおりレベル連動のままです(マイグレーション不要)。

## 品質保証の仕組み

問題は機械生成ですが、2段階でチェックしています。

1. **全数検証(自動)** — 生成しうる全問題(約7,700問)を列挙し、韓国語の助詞(을/를・이/가・은/는・(으)로・이에요/예요)、デンマーク語の性(en/et・denne/dette・min/mit・形容詞一致)、英語の a/an、文形式、意味の禁止パターン、ローマ字の回帰テストを機械チェックします。

   ```bash
   node tools/validate.js   # エラーがあれば exit 1
   ```

   言い換え(🔁)は文字列の形式(混入・空白・短すぎ・禁止パターン)だけを機械チェックします。
   **内容の自然さは機械では判定できないので、追加したら必ずLLMレビューにかけてください。**

2. **LLMレビュー(随時)** — 言語ごとのサンプルを言語モデルにレビューさせ、見つかった誤り・不自然さは generator.js の修正と validate.js の禁止パターン(`BANNED`)への追加で再発を防ぎます(2026-08 実施: 約420問をレビューし、ローマ字の鼻音化、「風が強い」の訳、very delicious などを修正済み)。

## 問題の追加方法

**単語を足す(最も簡単)** — `generator.js` の語彙配列に1行足すだけ。全テンプレートに自動展開され、1語で数十問増えます。
形容詞(`ADJS`)だけは必須フィールドが多いので注意してください。日本語の活用(`jp` / `jp_neg` / `jp_too` / `jp_adn`)と
デンマーク語の比較級・最上級(`da_er` / `da_est`、不規則が多く導出できない)は**全件明示**が必要です。

```js
// FOODS に追加する例
{ja:"はちみつ", ko:"꿀", da:"honning", g:"en", dad:"honningen", en:"honey", art:"", gen:"honey", dagen:"honning"},
```

- 韓国語の助詞はパッチムから自動選択されるので指定不要
- デンマーク語は `g`(en/et)と `dad`(限定形)を辞書で確認して指定
- 英語は `art`(a/an/""=不可算)を指定

**言い換えを足す** — 同じ意味を別の言い方でも表せるときは、答え合わせに出る🔁行を足せます。

```js
// 動詞ごと: ACTIONS のエントリに alt_ko / alt_da / alt_en(いずれも任意)を書く
{ja_p:"泳ぎます", …, alt_en:"swim は go swimming とも言えます(過去形は swam)"},

// 文型ごと: item() の第9引数に { alt: {...} } を渡す(難易度は { d: 3, alt: {...} })
yield item(`${o.ja}を買いたいです。`, …, "want to + 動詞の原形。",
  { alt: { en: "want to buy は would like to buy とも言えます(would like のほうが丁寧)" } });
```

書き方のルール:

- 基本形は `A は B とも言えます`。ニュアンス差があれば `( )` で一言添える
- 活用や助詞が変わるものはその場で書く(`過去形は saw` / `助詞が 를 → 가 に変わります`)
- **自然さに確信が持てないものは書かない**。誤った言い換えは模範解答より害が大きい
- 言い換えは時制をまたいで同じ文字列が出る(「毎日〜」「昨日〜」「どのくらいの頻度で〜」)ので、
  特定の時制に依存しない書き方にする

**文型を足す** — `generator.js` の `TEMPLATES` に1ブロック足すと語彙数ぶんの問題が一気に増えます。

**手書きの定番フレーズを足す** — `generator.js` の `CURATED` に追記します。

追加したら必ず検証を実行してください:

```bash
node tools/validate.js
```

## GitHub Pages へのデプロイ

```bash
cd ~/code/learn-languages-app
node tools/validate.js                    # 検証してから
git add index.html generator.js tools/ README.md .gitignore
git commit -m "Update LingoPop"
git push
```

初回セットアップは以下:

```bash
git init && git add . && git commit -m "Add LingoPop" && git branch -M main
gh repo create learn-languages-app --public --source=. --push
gh api repos/{owner}/learn-languages-app/pages -X POST -f "source[branch]=main" -f "source[path]=/"
```

(gh CLI がない場合は GitHub で `learn-languages-app` リポジトリを作成 → push → Settings → Pages で main / root を指定)

公開URL: `https://<ユーザー名>.github.io/learn-languages-app/`

`index.html` をダブルクリックするだけで動きます(fetch不使用のため file:// でもOK)。
